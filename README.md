# Headache Project

An Explainable AI system for headache classification, precautions, and treatment recommendations
using resting-state fMRI and machine learning.

## Dataset
- OpenNeuro MBSR (ds005016)

## Objectives
- Headache classification
- Explainable brain-region analysis
- Decision-support recommendations

## Tools
Python, Nilearn, Scikit-learn, SHAP, fMRIPrep
